# Security policy

Please do not report vulnerabilities in a public issue. Use the repository's
private GitHub Security Advisory form:
https://github.com/QTSurfer/qtstreamx/security/advisories/new

Include a reproducible description, affected version, and impact. Do not send
credentials or live provider secrets.

Supported security fixes target the latest release and the current release
candidate. Market-data provider credentials are runtime inputs and must never
be committed.
